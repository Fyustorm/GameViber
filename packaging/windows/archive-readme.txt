GameViber for Windows, without its installer
============================================

Start gameviber.exe: GameViber updates these files itself when a new version
comes out (Settings > Updates), so keep them in a folder you can write to.

GameViber needs ViGEmBus to capture the rumble games send to the gamepad:
https://github.com/nefarius/ViGEmBus/releases
and HidHide to hide your real gamepad from games, which would otherwise see
two (restart Windows after installing it):
https://github.com/nefarius/HidHide/releases
The installer (gameviber-<version>-windows-x86_64-setup.exe) installs both for you.

The guide: https://github.com/Fyustorm/GameViber/blob/main/docs/user-guide.md
